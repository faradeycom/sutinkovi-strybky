# Сутінкові Стрибки

Браузерний платформер про Ліхтарика: шість островів, 60 рівнів, 60 босів, міні-ігри, магазин і Ворогопедія.

Грається на телефоні й комп'ютері прямо в браузері. На телефоні краще тримати його горизонтально; гру можна додати на головний екран («Додати на головний екран»), тоді вона відкривається на весь екран, як застосунок.

Керування: на телефоні — кнопки ◀ ▶ і «Стрибок»; на комп'ютері — стрілки / A D, пробіл — стрибок, P — пауза.
